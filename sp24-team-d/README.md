# Boston University Bottle-Filling Station Project: Team D
This repository contains code to run a browser-based HTML page featuring an interactive map of BU's campus as well as a series of python programs and jupyter files used to attain floor-level data of BU classroom buildings' daily traffic. This project was created to accomplish the following:
    - Create a geospatial map showing broad areas of BU campus in need of new bottle-filling stations
        - Provide options for users to easily include or exclude residential areas
        - Provide options for increasing/decreasing importance placed in the map on residential buildings without air conditioning
        and buildings that primarily serve faculty.
    - Create a shortlist of floors for larger campus buildings that are most in need of bottle-filling stations

## Data
All data used for this project was provided by Boston University Sustainability, save for floor-by-floor occupancy over time data which was scraped from Boston University's student link. Links to each dataset can be found below:
    - [Campus Traffic Density](data/updated_densitymap_hourly_cleaned.csv)
    - [Bottle-Filling Station Coordinates](data/bottle_filler_coordinates.csv)
    - [Spring 2024 Courses](data/courses-spring2024.csv)
    - [BU Classrooms](data/classrooms.csv)

### Generating Data From Student Link
- [studentlink_scrap.ipynb](/sp24-team-d/studentlink_scrape.ipynb): This file contains python code that will open a Firefox browser and scrape the [BU student link](https://www.bu.edu/studentlink/).
Authentification is handled with a .env file not included in the repository.
Note that it takes close to 2 hours for the entire script to complete.
See [Spring 2024 Courses CSV File](data/courses-spring2024.csv) for the data extracted.

### Generating Data From BU Classroom Directory
- [bu_classroom_scrape.ipynb](/sp24-team-d/bu_classroom_scrape.ipynb): This file contains python code that will open a Firefox browser and scrape the [BU classroom directory](https://www.bu.edu/classrooms/find-a-classroom/).
Note that it takes close to 20 minutes for the entire script to complete.
See [BU Classrooms](data/classrooms.csv) for the data extracted.

### Data Augmentation and Intermediate Data Tables
To save computations we stored various tables as intermediate csv files.
- [Bottle Filler Coordinates](data/bottle_filler_coordinates.csv): This file maps the addresses of the bottle fillers to longitude lattitude coordinates, making it easy to compare density locations with water filler locations.
We explored many different geocoding APIs, which are shown in our helper functions found in [geoapify.py](geoapify.py), [geocoding.py](geocoding.py), and [google_maps.py](google_maps.py).
However, to generate the data we used the geoapify API since this was the cheapest and simplest option. 

- [courses-classrooms.csv](data/courses-classrooms.csv): This file is simply an intermediate result of the post processing done in [classroom_analysis.py](classroom_analysis.py)


### Data Cleaning
- [process_density.ipynb](/process_density.ipynb): This file contains python code necessary for processing the campus traffic density into a form usable by InteractiveMap.html. It does so by combining the individual timed traffic data for each wireless point into a single datapoint per wireless point that contains that wireless point's location as well as mean and max traffic.

- [classroom_analysis.ipynb](classroom_analysis.ipynb): This file contains python code necessary for running floor analysis from courses and classroom data. This script contains functions to generate a short list of our recommendations as well as generate time series data for a given floor and building.

### Data Analysis
- [Interactive Map](/InteractiveMap.html): This file can be run in a browser to see a Google Maps-based heatmap of bottle-filling stations and traffic density on BU campus. 

## How to Run
The project is split into two main parts: the heatmap and the floor-based analysis.

### Heatmap
The data to run [InteractiveMap.html](/InteractiveMap.html) is already provided in the data folder, however should a data update be necessary, new files can be generated by simply running the code cells sequentially in [process_density.ipynb](/process_density.ipynb). A Google Maps API key is required to run the file, and should be pasted in place of "YOUR_KEY" at the bottom of the file. Once opened in a browser, users must upload data files to the corresponding elements in the page, all of which should be found in [the data folder](/data). Users can then toggle layers as necessary. The "Mean/Max Scaled By Distance" layers attempts to highlight areas that are both high traffic and far from known bottle-filling stations. 

### Classroom Building Floor-Analysis
To run the script from scratch, ensure that [classrooms.csv](data/classrooms.csv), [courses-spring2024.csv](data/courses-spring2024.csv) and [bottle_fillers.csv](data/bottle_fillers.csv) all exist in the data folder. By running the first 19 cells, you will have created the intermediate data result (which is a table of all the three csv files essentially merged together). 

You can also run the script from the checkpoint, given that [courses-classrooms.csv](data/courses-classrooms.csv) is provided in the repo. To do so, skip to the section that says "If All Processing Done, Start Analysis Here". From there, all code should be runnable.
